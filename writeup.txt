Doubly Linked List:
The point of the doubly linked list is to have the songs in the order of my playlist. It acts as my actual playlist
where I can go to the next song and previous song. Also since every node has a .prev and .next pointer I can unlinking
a song anywhere in the playlist in O(1) constant time without using a loop. I built the link list myself so there is no 
built in collection cost to compare.

Hashmap:
I used a Hashmpa because it provides an insant lookup of a song in O(1) constant time. It maps song's IDs directly to
their playlist nodes. So instead of scanning through a list or an array in O(n) time to find a song my Hashmap allows
me to just jump straight to the track, and this allows me to locate and validate songs without any lag when the Library
grows.
